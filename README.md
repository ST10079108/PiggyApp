# PIGGYAPP

## DIRECTIONS FOR USE
1. clone github repository to IDE
2. open project
3. navigate to manage devices
4. run an emulator
5. wait for emulator to finishing starting
6. run application
7. enjoy PiggyPal

## FEATURES
- elegant UI
- custom categories
- Budget creation
- Transaction creation
